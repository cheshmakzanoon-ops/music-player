# Spotify App Remote SDK

This directory contains Spotify's published **App Remote 0.8.0** Android library.
It is an optional authenticated remote control for the official Spotify app.
It is not extracted from the reference APK.

- Upstream release: <https://github.com/spotify/android-sdk/releases/tag/v0.8.0-appremote_v2.1.0-auth>
- Asset: `spotify-app-remote-release-0.8.0.aar`
- Size: 132,749 bytes
- SHA-256: `b5a6dd880eaf01f63a871cba9ef7af77c341f8a94ffc8fdf2e9021f9a9d4c198`
- License and notices: [SPOTIFY-LICENSE.txt](SPOTIFY-LICENSE.txt), [SPOTIFY-NOTICE.txt](SPOTIFY-NOTICE.txt)

The SDK's native authorization flow requests the user's permission to control
the official Spotify application. It does not provide anonymous catalogue
streams, account bypass, region overrides or exportable Spotify downloads.
No client secret or private service credentials are included.
